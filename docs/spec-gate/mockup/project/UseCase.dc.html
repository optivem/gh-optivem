# UC-009 Refund order

A customer asks for a refund on an order that
has already been delivered.

## Main scenario

1. Customer requests a refund for the order.
2. System returns the whole order amount.
   → UC-009.1 Full refund returns the whole amount.

## Extensions

2a. Customer selects only some items.
    System returns the price of those items.
    → UC-009.2 Partial refund returns the selected items.

2b. More than 30 days since delivery.
    System rejects the refund.
    → UC-009.3 Refund is rejected after 30 days.
